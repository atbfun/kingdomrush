# 自检与独立审查记录

2026-10-19。`grill-with-docs` 不在技能清单或本机技能目录中，未执行该缺失技能。
按 `atb-game-porting` 的质量目标完成本地自检，并依据 `requesting-code-review` 启动独立只读审查。
以下推荐修复均已采纳。

| 问题 | 证据/根因 | 修复与验证 |
|---|---|---|
| 英雄加载后消失 | 字符串 ID `hero` 转 Number 得到 NaN，drawImage 静默不绘制 | 只用数字 ID 作为动画相位，sprite 接口再检查帧值；浏览器拦截实际 drawImage 参数确认全部有限 |
| 解码期间静音/暂停仍发声 | await 后状态已变，Web Audio 路径回落至 HTML Audio | 在 await 后与回落前重新验证静音/暂停；2 项回归先复现失败再修复通过 |
| 空格无法激活按钮 | 全局快捷键抢占原生 button 空格行为 | 交互控件保留键盘事件；浏览器聚焦声音按钮按空格，声音切换且游戏不暂停 |
| 敌人始终显示火焰/毒圈 | JPEXS 导出未执行 AS 的特效隐藏初始化 | 只在导出副本清理 46 个 Sprite 的具名状态特效 depth，重新生成 71 图集；目视检查与浏览器回归 |
| 本地并行请求偶发 reset | 默认 Python HTTPServer 的 request_queue_size 为 5 | 配套 ThreadingHTTPServer 设置 128 并使用动态端口测试；最终无请求错误 |
| 图片损坏导致绘制中断 | 图片 complete 不代表解码成功 | 所有 drawImage 校验 naturalWidth；无效图片注入测试、矢量地图/塔/角色兜底，无异常 |
| 暂停弹窗恢复的测试竞态 | 原生 dialog close 事件在后续事件任务触发 | 测试等待实际状态恢复，避免同步断言误判；未为测试改变游戏生命周期 |
